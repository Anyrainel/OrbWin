# Installed-product initial baseline

Observed 2026-10-24 on the ordinary per-user installation, Windows 11 Pro
26300.9711, WSL 2.7.11, shared warm WSL VM, Kubernetes disabled. Rancher and
Docker Desktop were not stopped. This is an initial measurement on one host,
not a product comparison, independent WSL memory attribution or broad OS claim.

`ORBWIN_QUALIFY_OWNED=1 node scripts/measure-baseline.mjs` requires the installed
identity and qualified coexistence record. Run outside packaged/virtualized
development hosts so LocalAppData is the actual Windows profile. It requires no
running OrbWin containers and a running installed UI. The harness uses the
bundled clients and backend, exact labeled fixtures, current-start readiness,
actual daemon identity, persistent marker checks and global config hashes.

16 MiB files are a reproducible smoke baseline, not a realistic throughput or
random-I/O benchmark. Working-set sums include shared pages; private bytes are
reported separately. Shared `vmmemWSL` is deliberately excluded.
